## What is csharp-drill?

csharp-drill is a web-based resource for preparing for C# and .NET interviews. It is built for short, efficient practice sessions, allowing you to move quickly through flashcards and quiz prompts with very little setup and strong keyboard support.

The entire application is delivered as one self-contained page. You can open it without installing a separate desktop application, while browser storage keeps your progress available for future spaced repetition sessions.

## Using the App

Choose either the recall-card mode or the multiple-choice quiz mode when you begin.

A normal session looks like this:

1. Load the page in a modern browser.
2. Read the prompt shown on a card.
3. Respond using the keyboard, or choose an answer in MCQ mode.
4. Allow the Leitner schedule to determine the next review.
5. Come back later and resume using the progress saved in the browser.

Switching between fast recall drills and quiz rounds provides practice with both retrieval and recognition during interview preparation.

## Frequently Asked Questions

### How is study progress stored?

Your progress is saved in the browser. To resume the same session, continue using the same browser profile.

### Does the tool work offline?

Yes, when the page and required assets are available locally or already present in the browser cache. A separate application installation is not required.

### How can I edit the study material?

Modify the page data or configuration used by your hosted copy. The precise location varies according to how the repository is packaged.

### Why might the page fail to load?

Verify that you are using an up-to-date browser and that your local file or static host is serving the HTML page correctly.
